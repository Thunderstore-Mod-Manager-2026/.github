## Overview

Thunderstore Mod Manager is a Windows application for discovering and managing mods for supported PC games.

The manager connects with the Thunderstore mod ecosystem, allowing players to browse available community content, install mods, create separate profiles, update existing packages, and manage configurations from one interface.

Thunderstore currently lists more than **110,000 mods across 300+ games**, with large communities around titles such as Lethal Company, Valheim, Risk of Rain 2, R.E.P.O., H3VR, and PEAK.

The application is designed to make PC game modding more convenient by keeping downloads, profiles, dependencies, configurations, and updates organized in one place.
